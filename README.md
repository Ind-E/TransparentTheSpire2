Makes most backgrounds in the game transparent.

Tested on windows, wayland, and xwayland.

## Installation
Copy the `override.cfg` file from the [latest release](https://github.com/Ind-E/TransparentTheSpire2/releases/latest) into the same folder as your Slay the Spire 2 executable (typically `Steam/steamapps/common/Slay the Spire 2/`)
- This only needs to be done once, and does not need to be redone when updating
- It's fine to leave the `override.cfg` file there when not playing with this mod, but it may result in slightly worse performance

Extract the `.zip` from the [latest release](https://github.com/Ind-E/TransparentTheSpire2/releases/latest) into your Slay the Spire 2 mods folder (create it if it doesn't exist)
- Windows and Linux: `Steam/steamapps/common/Slay the Spire 2/mods/`
- Mac: `Steam/steamapps/common/Slay the Spire 2/SlayTheSpire2.app/Contents/MacOS/mods/`
